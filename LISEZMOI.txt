SS’HEALTHY - Installation sur WAMP
====================================

1. Copier le dossier "zig_healthy" dans C:\wamp64\www\

2. Ouvrir phpMyAdmin (http://localhost/phpmyadmin)
   -> Onglet "Importer" -> choisir bd/zig_healthy_db.sql -> Exécuter
   (La base zig_healthy_db se crée avec 12 plats de test)

3. Vérifier le port MySQL dans includes/config.php
   (actuellement 3308, comme ton installation)

4. Ouvrir http://localhost/zig_healthy/

Compte admin de test :
   Email : admin@sshealthy.sn
   Mot de passe : admin123

Pages livrées dans cette étape :
   - index.php  (accueil)
   - menu.php   (menu filtrable par objectif + catégorie)

Prochaines étapes :
   - plat.php (fiche détaillée)
   - inscription.php / connexion.php
   - panier.php / commande.php
   - admin/ (gestion plats et commandes)
